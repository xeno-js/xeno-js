# Anduril Kernel

Core separato dal frontend, pensato per ospitare i moduli DDD/Clean Architecture.

Struttura base:

- `src/modules/shared/domain/contracts`
- `src/modules/shared/application`
- `src/modules/shared/infrastructure`
- `src/modules/shared/presentation/di`
- `src/modules/features`

In questa fase il kernel contiene solo scaffolding e configurazione, senza implementazioni di business.
